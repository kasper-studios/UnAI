# Терминология UnAI

Для однозначного понимания архитектуры:

1. **Runtime (Рантайм / Ядро)**: Нижнеуровневая инфраструктура, хостящая процессы воркспейсов. Отвечает за:
    - Жизненный цикл (Lifecycle) процессов;
    - Системную шину (System Bus);
    - Маршрутизацию сообщений (IPC / Call Dispatcher);
    - Регистрацию и обнаружение возможностей (Capability Graph + Resolver);
    - Управление состоянием ноды.
    *Рантайм не знает, ЧТО делает воркспейс — он знает, КАК воркспейс общается с системой.*

2. **Workspace (Воркспейс)**: Специализированная логика или приложение, работающее поверх Рантайма.
    - Реализует конкретный домен (например, `Web Workspace` для браузера, `Discord Workspace` для общения).
    - Описывает свои Capabilities и API через манифест (`RuntimeManifest` / `WorkspaceManifest`).
    - Подключается к Рантайму через шину и получает доступ к сервисам системы (например, к `Notification Service`).

*Воркспейс использует Рантайм для изоляции и связи.*
